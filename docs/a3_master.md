# A3 Мастер — упрощённый режим частного мастера

Отдельный лёгкий интерфейс поверх того же backend для мастера, работающего
одному: Сегодня, Новая запись, Голос, Клиенты, Деньги. Отдельного приложения
нет — режим включается настройкой компании.

## Включение

Настройки компании → «Режим интерфейса» → «Частный мастер — упрощённый»
(`company_settings.mode = 'master'`). Владелец и менеджеры после входа
попадают на `/master`; исполнители по-прежнему на свою панель.

## Экран «Сегодня» (`/master`)

- Сводка: число записей на сегодня, выручка сегодня и за месяц.
- Список записей дня со временем, клиентом, статусом и ссылкой на заявку.
- Четыре крупные кнопки: Новая запись (`/create-task`), Голос
  (`/master/voice`), Клиенты (`/clients`), Деньги (`/finance`).

## Голос (`/master/voice`, глобально `/voice`)

Голосовой ввод через Web Speech API браузера (ru-RU; работает в Chrome и
Safari). Распознанный текст отправляется одной кнопкой **«Отправить
помощнику»**: классификатор намерений сам решает, что делать — «запиши…» →
черновик заявки (с извлечением клиента, телефона, адреса, даты и услуги),
«найди…» → поиск заявки, «напомни…» → напоминание (заметка помощника с датой
follow-up), остальное → заметка. Ручные кнопки «Запись / Поиск / Напомнить»
остаются под основной. Страница доступна владельцу и менеджеру на любом
тарифе; на главной — большая кнопка «Голосовой помощник». Голос никуда не
отправляется: распознавание выполняет браузер; ошибки микрофона показываются
с пояснениями на русском.

## Границы режима

- Это упрощённая «витрина»: все полные разделы CRM остаются доступны по
  прямым ссылкам.
- На будущее: голосовое создание записи без заметки-посредника и ещё более
  компактная навигация — по обратной связи пилотов.
