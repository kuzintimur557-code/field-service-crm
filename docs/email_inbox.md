# Email Inbox / AI Dispatcher

Приём писем от клиентов, разбор содержимого и создание заявок с
подтверждением менеджером. Заявки и клиенты никогда не создаются
автоматически без подтверждения.

## Приём писем

`POST /api/inbox/email` с заголовком `x-inbox-secret: $INBOX_WEBHOOK_SECRET`.

Два формата:

1. JSON (`Content-Type: application/json`):

```json
{
  "company_id": 1,
  "provider": "mailgun",
  "message_id": "<id@provider>",
  "from_email": "client@example.com",
  "from_name": "Имя Клиента",
  "subject": "Тема",
  "text": "Текст письма",
  "raw": "Исходник письма (необязательно)",
  "received_at": "2026-09-28 10:00"
}
```

2. Сырое письмо RFC822 (`Content-Type: message/rfc822` или любой другой):
   тело запроса — исходный `.eml`, компания передаётся параметром
   `?company_id=1`.

Дедупликация: уникальный ключ `(company_id, dedupe_key)`, где dedupe_key —
`message_id` провайдера, а при его отсутствии хэш отправителя, темы, даты и
текста. Повторная доставка возвращает `{"ok": true, "duplicate": true}`.

Лимиты: тема 500 символов, текст 100 КБ, исходник 200 КБ.

## Разбор

При сохранении извлекаются: телефон, адрес, имя, дата («завтра», «12
декабря», «в пятницу», `05.10`) и услуга по каталогу компании. Результат
хранится в `email_messages.extracted_json` и показывается на странице
письма.

## Подтверждение

- `/inbox` — список писем (boss/manager), фильтры по статусу.
- `/inbox/{id}` — исходное письмо, извлечённые поля, черновик заявки,
  подсказка свободных окон (дата + исполнитель с учётом занятости и
  недоступности).
- `POST /inbox/{id}/confirm` — создаёт клиента (дедупликация по
  телефону/email внутри компании) и заявку со статусом «Новая», назначает
  выбранного исполнителя и уведомляет его. Повторное подтверждение того же
  письма не создаёт дубликат.
- `POST /inbox/{id}/reject` — письмо отклоняется.

Модуль отключается feature-флагом «Почта» (`inbox`) в настройках компании.

## Приём из обычного почтового ящика (IMAP-поллер)

Если у компании есть обычный ящик (Яндекс, Mail.ru, Gmail), webhook не нужен:
`scripts/email_poller.py` подключается к ящику по IMAP, забирает непрочитанные
письма и пересылает их на `POST /api/inbox/email` в виде сырых `.eml` (с
указанием компании в `?company_id=`). Успешно доставленные письма помечаются
прочитанными; при ошибке доставки остаются непрочитанными и повторяются.

Настройка (env-переменные, см. `.env.example`):

```
IMAP_HOST=imap.yandex.ru
IMAP_PORT=993
IMAP_USER=заявки@компания.ru
IMAP_PASSWORD=<пароль приложения>
INBOX_COMPANY_ID=1
APP_BASE_URL=http://127.0.0.1:8000
INBOX_WEBHOOK_SECRET=<тот же секрет, что у приложения>
```

Запуск вручную: `python scripts/email_poller.py`. Для постоянной работы —
cron каждые 1–5 минут:

```
*/2 * * * * cd /srv/app && python scripts/email_poller.py >> /var/log/email_poller.log 2>&1
```

Для Яндекса/Google включите «пароль приложения» в настройках аккаунта.
